💻 Key Code Explained (PHP + Azure SQL)

1. Connect to Azure SQL (db_config.php)
// Your Azure SQL server address (from Azure Portal)
$server = "yourserver.database.windows.net";

$options = [
  "Database" => "EventRegistrationDB",
  "Uid" => "admin_user",
  "PWD" => "YourPassword!",
  "Encrypt" => true, // Azure always uses secure connection
];

$conn = sqlsrv_connect($server, $options);
2. Insert Data Safely (register.php)
// ✅ Parameterized query — PREVENTS SQL Injection attacks!
$sql = "INSERT INTO registrations
         (full_name, email, university)
         VALUES (?, ?, ?)";

// The ? placeholders get filled safely — not by string joining!
$params = [$full_name, $email, $university];
sqlsrv_query($conn, $sql, $params);
3. Read Data Live (registrations.php)
$sql = "SELECT * FROM registrations ORDER BY registered_at DESC";
$rows = sqlsrv_query($conn, $sql);

while ($row = sqlsrv_fetch_array($rows, SQLSRV_FETCH_ASSOC)) {
  echo $row['full_name'] . " — " . $row['university'];
}

🔧 Setup Checklist for Students

1

Create Azure SQL Database

Go to portal.azure.com → Create resource → SQL Database → Choose "Basic" pricing (free trial available)

2

Add your IP to Azure Firewall

SQL Server → Networking → "Add your client IP" → Save. This lets your computer connect to Azure.

3

Edit db_config.php

Paste your Server Name, Database name, Username, and Password into the config file.

4

Visit setup.php once

This creates the "registrations" table in your Azure SQL database. Delete setup.php after running!

5

Open index.html and register!

Fill the form → check registrations.php → your data is live in the cloud. Share the link with a friend!
